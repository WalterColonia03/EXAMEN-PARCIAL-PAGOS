# Mejoras de PagoControl

Este archivo funciona como acceso rápido. La fuente completa y trazable se mantiene en:

- `planificacion_scrum/08_INVESTIGACION_DE_REFERENTES_Y_BENCHMARK.md`: investigación y decisiones de adaptación.
- `planificacion_scrum/09_MATRIZ_DE_MEJORAS_Y_TRAZABILIDAD.md`: estado de cada mejora.
- `planificacion_scrum/10_PLAN_EXPERIMENTAL_PROTOTIPO.md`: reglas del prototipo experimental.
- `planificacion_scrum/11_GUIA_VALIDACION_MANUAL_DESDE_CERO.md`: recorrido Gerente → Asistente → Gerente desde una base operativa vacía.
- `planificacion_scrum/evidencias/EXP-LAB_IMPLEMENTACION_2026-10-16.md`: código, pruebas, límites y validaciones pendientes.
- `planificacion_scrum/evidencias/EXP-LAB_REINICIO_CONTROLADO_2026-10-16.md`: respaldo, conteos y controles del reinicio previo a la prueba.
- `planificacion_scrum/evidencias/EXP-LAB_RECUPERACION_ACCESO_2026-10-16.md`: diagnóstico, implementación y comprobaciones de la recuperación segura de acceso.

## Estado actual

Los experimentos `EXP-LAB-01` a `EXP-LAB-05`, `EXP-LAB-10` y `EXP-LAB-11` están verificados técnicamente. `EXP-LAB-06` a `EXP-LAB-09` tienen una variante funcional con límites explícitos que requieren decisión del responsable del producto. Nada de este laboratorio se considera todavía `Done` del Sprint ni fue enviado a GitHub o Jira.

## Siguiente decisión

La versión 0.9 incorpora acceso y recuperación segura y está lista para que el responsable del producto reinicie `11_GUIA_VALIDACION_MANUAL_DESDE_CERO.md` desde la fase 0; después podrá aceptar, reformular o descartar cada variante. La guía todavía no se considera ejecutada. Solo entonces se convertirán los comportamientos aceptados en nuevas Historias de Usuario estimables.
